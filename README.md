# KITE showcase (GitHub Pages)

This branch is the published page at https://hengyuli-ozaki-lab.github.io/kite_population_simulator/: one
self-contained `index.html` with the held-out results on Epstein 2021, SocSci210 and Arechar 2023, and its social-card
image `og.png`. The code, frozen criteria, evaluation records and aggregates behind every number are on
[`main`](https://github.com/HengyuLi-Ozaki-lab/kite_population_simulator).

The page carries aggregate statistics and model outputs only: no survey microdata and no original headline text
(Arechar headlines appear as rewritten topic tags).
