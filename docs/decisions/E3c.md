# E3c：自回归模拟 —— 在干净数据上基本成立，但证据只有一个研究

日期：2026-09-21 · 模型 `jev-1.13.0`（p3）· 非作弊：模拟对象只用自己抽到的答案作历史
数据：**开发集** nj5dx、sffyb，约 600 人；窗口 0 / 1 / 3 共约 $0.8
复现：`uv run python scripts/e3c_autoregressive.py --studies nj5dx sffyb --windows 0 1 3 --max-usd 3`

## 设计

每个模拟对象按题目顺序作答，每题从预测分布中**抽取**一个答案，最近 `window` 条**自己抽到的**答案进入下一题的 state。不借用任何真人作答。窗口 0 即 E3 的独立作答，作为基线。

## 合并结果（被污染，见下）

| 窗口 | 模拟 / 真实 | 结构 | 模拟 相邻 / 远距 | 真实 相邻 / 远距 |
|---|---|---|---|---|
| 0 | 36% | 0.267 | 0.088 / 0.076 | 0.281 / 0.202 |
| 1 | 51% | 0.517 | 0.228 / 0.085 | 0.281 / 0.202 |
| 3 | 51% | 0.549 | 0.187 / 0.093 | 0.281 / 0.202 |

## 数据结构问题

nj5dx 的模拟跑了 19 轮，而它只有 11 道题。原因：**同一个人的同一个 `task_num` 下有多行，刺激文本各不相同**——是被试内设计，每人对多个刺激回答同一个问题，数据重构时都标成了同一个 `task_num`。1,326 组全部来自 nj5dx，人口学相同，刺激文本全部不同，其中 865 组答案也不同。

这在自回归模拟里会人为制造局部结构：一个人连续回答"同一问题、不同刺激"，历史窗口里塞满了近乎相同的题目。**合并结果因此被污染**，尤其是"相邻 vs 远距"这个诊断。范围与影响见 `docs/data/socsci210-schema.md`。

## 分研究结果（sffyb 干净，nj5dx 受污染）

| 研究 | 窗口 | 模拟 / 真实 | 结构 | 模拟 相邻 / 远距 | 真实 相邻 / 远距 |
|---|---|---|---|---|---|
| **sffyb** | 0 | 45% | 0.159 | 0.082 / 0.078 | 0.277 / 0.153 |
| **sffyb** | 1 | 73% | 0.604 | 0.291 / 0.094 | 0.277 / 0.153 |
| **sffyb** | 3 | **75%** | **0.658** | 0.234 / 0.110 | 0.277 / 0.153 |
| nj5dx | 3 | 31% | 0.419 | 0.130 / 0.071 | 0.286 / 0.259 |

## 一条事先判据是错的

事先写定的成功判据包含"相邻题 ≈ 远距题"，照抄判据则是"相邻题远高于远距题**而真实数据里两者相当**"。两条都**隐含假设了真实数据没有局部结构**——而真实的 sffyb 里相邻 0.277、远距 0.153，**比值 1.81**，真人本身就有很强的局部一致性。按字面执行，真人自己都不及格。

判据的本意是"模拟的局部集中程度不应超过真人"。按本意比较集中度比值（相邻 / 远距）：

| | 比值 |
|---|---|
| 真人 sffyb | 1.81 |
| 模拟 sffyb，窗口 1 | 3.10 |
| 模拟 sffyb，窗口 3 | **2.13** |

在此明确记录判据有误，并说明按本意如何读，而不是悄悄改写判据。

## 判定（以 sffyb 为准）

**基本成立，带一个照抄成分。**

- 量级：真实的 **75%**，落在事先写定的 50%–150% 区间内；
- 结构：从独立作答的 0.159 升到 **0.658**，四倍；
- **稳定个体倾向**（远距题）：0.110 对真实 0.153，达到 **72%**——这才是"一个人前后一致"的核心度量；
- 局部集中：2.13 对真人 1.81，**多出约 18%**，有照抄上一题的成分，但不是主导。窗口 3 明显比窗口 1 更接近真人（2.13 对 3.10），更长的历史削弱了照抄。

## 必须说清楚的限定

**这是一个研究的证据。** nj5dx 受污染不可用，所以判定实际只建立在 sffyb 上。在 31 个干净的开发研究里重复验证之前，不能宣称 C2 已经保住。

## 对 E3 的复核

E3 的 5 个研究里，nj5dx（65% 的行）与 9263n（23%）受同一问题影响。只看干净的 mp3dr、sffyb、r5hwx：独立采样的题间相关仍为真实的 **12%**（0.036 对 0.308），与报告值一致。**E3 的核心结论稳健**；受污染的两个研究只把结构相关抬高了一些（0.751 对干净的 0.495）。
