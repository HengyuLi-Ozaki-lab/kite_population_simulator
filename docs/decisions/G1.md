## 指标对齐：为什么原始值不能直接比

我们与论文都能算出一个**不依赖模型**的均匀猜测行。两者在同一套归一化约定下仍然不同：

| | 我们（准备好的测试集） | 论文 |
|---|---|---|
| 均匀猜测，分布距离（论文口径） | **0.1771** | **0.2030** |
| 均匀猜测，准确率（随机抽取） | 0.6006 | 0.612 |

准确率吻合到 0.011，说明指标实现正确；分布距离差 0.026，来自**任务集不同**：我们排除了 14 个超过 101 级的高基数任务（301、25,001、86,914 级），而均匀预测在那些超长量表上离人类答案极远，会把论文那一行拉高。

因此**原始数字不可并排比较**。下表用各自的均匀基线归一化，以这个不依赖模型的锚点吸收任务集差异：

| 系统 | 原始 | 除以各自的均匀 |
|---|---|---|
| **Jev p3（本次，零样本）** | **0.1519** | **0.858** |
| GPT-4o（论文，零样本） | 0.1740 | 0.857 |
| GPT-4o 少样本（论文） | 0.1610 | 0.793 |
| Socrates-LLaMA3-8B SFT（论文，在 170 个研究上微调） | 0.1530 | 0.754 |
| Socrates-Qwen2.5-14B SFT（论文，同上） | 0.1510 | 0.744 |
| 经验下界（论文） | 0.1250 | 0.616 |

## G1：核是否可信 —— **通过**

| 判据（预注册） | 结果 |
|---|---|
| 强通过：零样本 ≤ 0.174（不差于 GPT-4o） | 原始 0.1519 ≤ 0.174 ✔；归一化 0.858 对 0.857 ✔ |
| 明显优于均匀猜测 | 0.1519 对 0.1771，缩小了均匀→下界差距的 34% ✔ |
| 单位成本 ≤ 旗舰 LLM 的 1/50 | **未验证**（见下方"未完成"） |

**结论：通过，但必须按打平来写，不能写成胜出。** 字面判据「≤ 0.174」满足，其意图「不差于 GPT-4o」也满足——但只是**打平**：归一化后 0.858 对 0.857。Jev 明确落后于 GPT-4o 少样本（0.793）和两个在 170 个研究上微调过的 Socrates 模型（0.744 / 0.754）。任何声称「Jev 胜过 GPT-4o」的表述都是把任务集差异当成了模型差异。

真正的看点不是精度而是代价：**每千次预测 $0.033、p50 延迟 243 毫秒**，在零样本条件下达到与 GPT-4o 相当的水平。

## G1b：核是否对处境敏感 —— **通过**

| 统计量 | 值 |
|---|---|
| Pearson r（任务内中心化，跨条件） | **0.3846** |
| 置换检验 p | **0.0005** |
| 空分布 95 分位 | 0.1444 |
| bootstrap 95% 区间 | [0.2031, 0.5766] |
| 回归斜率（预测→真人） | 0.5037 |
| 变动幅度比 | 0.7635 |
| 参与统计的任务 / 单元 | 167 / 715 |

| 判据 | 结果 |
|---|---|
| 预注册：r ≥ 0.25 且 bootstrap 下界 > 0 | 0.3846 ≥ 0.25 ✔；下界 0.2031 > 0 ✔ |
| 勘误二（跑测试集前声明的更强判据）：置换 p < 0.01 且 r > 空分布 95 分位 | p = 0.0005 ✔；0.3846 > 0.1444 ✔ |

**结论：通过，新旧两套判据都满足。** r 从开发集的 0.640 降到 0.3846——在用开发集做过选择之后，这种回落是预期内的，且仍然远高于两条线。

**这正是本项目的方法学论点，现已在测试集上成立**：那个把实验条件合并后的真人分布基线，在聚合指标上得 0.0339（远好于 Jev 的 0.1519、也远好于论文里任何模型），但它区分实验条件的能力是 **0**。**聚合指标可以被一个对模拟毫无用处的预测器刷到接近满分。**

## 其他观测

- **熵比中位数 1.126**（p25 1.042、p75 1.362；723 个单元中仅 2 个属低熵）。在稳健口径下，Jev 的分布确实**比真人更平**而非更尖——与 mode collapse 的担忧方向相反。此前因均值不稳而搁置的这个结论，现在有了可靠依据。
- **ECE 0.0382**，接近均匀基线的 0.0299，远好于开发集上 Choice 问法的 0.23–0.25。逐选项 Noul 的校准优势在测试集上保持。
- **准确率 0.7334**（中位数规则）对均匀的 0.7060。用随机抽取口径则是 0.6305 对 0.6025。两种口径下领先幅度都不大。

## 未完成，以及为什么

1. **自跑的 LLM 基线（Task 22）**：没有 OpenAI / Anthropic 的 key。这使「单位成本 ≤ 旗舰 LLM 的 1/50」这条判据**未经验证**——Jev 侧的 $0.033/千次是实测的，对照侧不是。论文若要写成本对比，必须补这一项。
2. **任务集完全对齐**：要让高基数任务也纳入，需要重跑这部分，而**账户额度已耗尽**。在补齐之前，与论文数字的比较只能用上面的归一化形式。
3. **缺失的 32 条预测**（0.023%）：额度在收尾处耗尽所致，对指标无实质影响。
4. **E1（OpinionQA）**：数据源不可得，见 `docs/data/opinionqa-schema.md`。
