# C2 / C3：误信息领域的微观验证（Arechar et al. 2023）

模型 `jev-1.13.0`（p3）· 划分：`configs/eval/arechar_split.yaml`（先于下载提交，93a8ec6）· 判据：`configs/eval/arechar_criteria.yaml`（标定之后、读取任何留出作答之前提交，d826501）
数据说明：`docs/data/arechar-schema.md` · 驱动：`scripts/c2_arechar.py`

## 设计

模型读到的就是受访者读到的，而且顺序相同：问卷开头的说明（转发或准确性）；prompt 条件先有 49 词的"预测试"说明和四条中性标题之一（按原问卷的随机方式分配）；提示条件先有四条提示；然后是标题和问题。所有文字从问卷文件读出，不手抄。persona 只用处理前的变量和不可能被一屏提示改变的人口学变量（划分文件附录）。

## C2：标定（美国 × A 半，2026-09-22）

2,118 名受访者、21,722 条预测、$0.69。运行目录 `results/c2/20260922-004807-calibration`。

| 指标 | 模型 | 真人参照 | 空分布 95 分位 |
|---|---|---|---|
| 标题层面相关：转发 | 0.720 | 可靠度 0.898 → **80%** | 0.356 |
| 标题层面相关：准确性 | 0.871 | 可靠度 0.984 → **89%** | 0.353 |
| 真假分辨：准确性条件 | +1.27 | +1.49 | 0.53 |
| 真假分辨：只问转发 | +0.42 | +0.57 | 0.22 |
| **accuracy prompt 效应（对转发分辨力）** | **−0.03** | **+0.15**，区间约 [0.00, 0.31] | ±0.035 |
| 提示效应 | +0.02 | −0.05，区间 [−0.21, 0.09] | ±0.036 |
| 个体层面（同一标题内） | 0.239 | — | 0.010 |
| 单元分布距离 | 0.083 | 均匀猜测 0.119 | — |

读法：

- 核复现了这一领域的核心现象——**人能分辨真假，但转发时只用上一部分**（模型 1.27 对 0.42，真人 1.49 对 0.57）。哪些标题会被转发、被相信，它排得相当准；同一标题下哪些人更会转发，它也有显著的区分力（persona 里的"会分享哪类新闻"起了作用）。
- **它没有复现 accuracy prompt 的效应。** 它确实对 prompt 上下文有反应，但方向不对：预测假新闻转发 +0.06、真新闻 +0.03，而真人是 −0.21 与 −0.06。
- 模拟人数从每条件 100 人起，标题层面的一致性已经平稳（转发 0.70、准确性 0.87），留出阶段取每国 × 条件 100 人。

## C2b：点明机制的诊断（判据冻结之后，仅用标定数据，不是门槛）

判据文件里预先写定的一句话——"This made the respondent think about whether headlines are accurate."——加进 prompt 条件的上下文，对同一批 400 名美国受访者配对比较（$0.035）：

| 模型 | prompt 效应 | 假新闻转发变化 | 真新闻转发变化 |
|---|---|---|---|
| 忠实描述 | −0.081 | +0.005 | −0.076 |
| 点明机制 | −0.056 | −0.031 | −0.086 |

配对变化：假新闻 −0.036，真新闻 −0.010，分辨力约 +0.03——方向对了，但只有美国全样本真人效应的约五分之一。**直接告诉它机制，它的转发预测也几乎不动。**"能表示、只是推断不出"只得到很弱的支持；主要是它的转发预测对这种注意力操纵不敏感。

旁证：这 400 人子样本里真人的 prompt 效应是 −0.09，与全样本 +0.15 方向相反——单个国家、每条件百人量级的真人效应被噪声主导，判据按跨国汇总检验是必要的。

## C3：留出部分（按 d826501 提交的判据，运行一次）

运行目录 `results/c2/20260922-011615-held_out`：6,400 名受访者（每国 × 条件 100 人）、122,253 条预测、$3.91（账本 3.905），全部真人参照用所有受访者。

### 判定

| 部分 | 条目与个体门槛 | accuracy prompt | 数字素养提示 |
|---|---|---|---|
| 新标题（美国 × B 半） | **通过** | **失败**：模型 −0.102（空 p95 +0.082），真人 +0.344 [0.204, 0.493] | **失败**：模型 +0.056（空 p95 +0.081），真人 +0.156 [0.017, 0.286] |
| 新国家（15 国 × A 半） | **通过**：转发 15/15、准确性 15/15、分辨 15/15 | **失败**：模型 −0.034（空 p95 +0.016），真人 +0.090 [0.053, 0.128] | **失败**：模型 +0.005，真人 +0.058 [0.016, 0.093] |
| 两者皆新（15 国 × B 半） | **通过**：15/15、15/15、15/15 | **失败**：模型 −0.060（空 p95 +0.016），真人 +0.127 [0.087, 0.162] | **失败**：模型 −0.003，真人 +0.075 [0.042, 0.110] |

个体层面（同一标题内对人的区分）：0.167、0.130、0.125，空分布 95 分位分别为 0.028、0.006、0.008，全部通过；低于美国标定集的 0.239。

判据里事先写下的预测是"prompt 很可能失败"，结果如此。数字素养提示在美国标定集上真人效应不可靠（判为不适用），在留出部分真人效应可靠为正，模型同样没有跟上。

### 逐国（新国家 / 两者皆新）

标题层面相关：转发 0.56–0.83 / 0.61–0.89，准确性 0.73–0.87 / 0.69–0.95；各国真人可靠度 0.89–0.98 / 0.96–0.99。

按问卷语言（事先声明的调节变量，中位数，转发 / 准确性）：

| 组 | 新国家 | 两者皆新 |
|---|---|---|
| 译文（9 国） | 0.736 / 0.852 | 0.820 / 0.823 |
| 英语（AU、NG、UK、ZA） | 0.711 / 0.832 | 0.711 / 0.838 |
| 混合（IN、PN） | 0.775 / 0.821 | 0.699 / 0.765 |

**读译文的国家没有吃亏。** 模型始终读英文，而这 9 国的受访者读的是西语、葡语、意语、中文、阿语、俄语译文；标题层面的一致性与英语国家相当，甚至略高。

prompt 效应的符号，在真人效应可靠的国家上：新国家 5 国中 1 国一致，两者皆新 8 国中 4 国一致——不高于抛硬币。模型的效应在新国家 15 国中 11 国为负，两者皆新 15 国中 12 国为负。

### 读法

1. **"哪些标题会被相信、被转发"这一级，跨越了新标题、新国家、新语言。** 这是整个项目里最强的一条正面证据：在读取任何留出数据之前写定的判据下，30 个国家 × 半边组合全部通过。
2. **两种干预都看不见，而且 prompt 的方向是反的。** 两个 15 国部分里，模型的汇总效应都低于其空分布的 5 分位附近（约 −0.016），也就是说它**系统性地**预测 prompt 会让分辨力略微变差。加上标定阶段"点明机制也只动五分之一"的诊断，结论是：它的转发预测对注意力类干预不敏感，而且留下的那一点反应方向不对。
3. **描述性观察（不在判据里）：模型几乎不区分国家整体的分辨力。** 准确性条件下它在各国的真假分辨都在 1.14–1.30 之间，真人则从 0.71（印度，两者皆新）到 2.00（英国，新国家）。persona 里的国家和人口学信息，让它排对了标题，却没有让它分出"哪国人更会分辨"——这是"看得见处境、看不见人"在人群层面的对应。
4. **个体层面的区分力在留出国家里减弱**（0.24 → 0.13），但始终远高于空分布。

### 对项目的含义

- G-C（误信息领域的微观验证）：**条目层面通过、干预层面失败**，两者都是在事先判据下的明确结论。
- 风洞在这个领域被授权的用途：**内容层面的初筛**（哪些说法更可能被相信或转发），跨语言可用；**不被授权**：预测注意力类、提示类干预的效果与方向，以及比较不同人群的整体易感性。

## C3b：旗舰档对照（GPT-6 Astra，高推理强度，2026-09-22）

设计先于旗舰档的任何留出预测提交（`configs/eval/flagship_baseline.yaml`，ffcb4a7）：只跑"两者皆新"部分（15 国 × B 半），每国 × 条件 30 人，嵌套在核的 100 人之内；主条件 share_only 与 prompt，tips 为次要条件（主条件跑完、额度允许时再跑）。LLM 读到的 persona、上下文、标题、问题和选项与核完全相同；每批只含一个条件，批内标题互不相同、受访者互不相同（否则它能对照同一标题有无 prompt，这是核没有的便利）。核在同样这批受访者上重新计分。判据是 d826501 冻结的那份，原样套用。

驱动 `scripts/c3_llm_arechar.py`，运行目录 `results/c3-flagship/20260922-133803-gpt-6-astra`。主条件 8,559 条预测、619 次调用、3,907,226 token、70 分钟（其报告另存为 `report-primary.json`）；tips 4,274 条、314 次调用、1,902,033 token、36 分钟。合计 12,833 条预测、5,809,259 token，无失败。下文的判定取自两次运行后的 `report.json`；prompt 的数字与主条件报告完全相同。

### 次要分析（`scripts/c3b_flagship_paired.py`，写于判定入档之后，不是门槛）

按工作规则，对已打开的留出预测只做事先有定义的分析：真、假标题两条通道的拆分沿用 C2 / C2b 在标定数据上的做法；置换 p 与配对差值用的是判据本身的国内条件置换。

|---|---|---|---|---|---|
| **accuracy prompt** | | | | | |
| Astra | +0.052 | [+0.010, +0.094] | 0.012 | −0.045 | −0.097 |
| Jev | −0.025 | [−0.058, +0.011] | 0.92 | +0.028 | +0.053 |
| 真人 | +0.127 | [+0.089, +0.165] | — | −0.053 | −0.180 |
| **Astra − Jev（配对）** | **+0.077** | **[+0.055, +0.099]** | **0.0002** | −0.073 | −0.150 |
| **数字素养提示** | | | | | |
| Astra | +0.045 | [+0.002, +0.088] | 0.026 | −0.055 | −0.100 |
| Jev | +0.015 | [−0.022, +0.053] | 0.23 | −0.013 | −0.028 |

配对差值的做法：两个模型预测的是同一批人、同一批标题，效应之差就等于"每人两份预测之差"上的效应，所以可以直接用判据的国内条件置换作空分布，按国家 × 条件重抽受访者给区间。Astra 高于 Jev 的国家：prompt 13/15，tips 11/15。

逐国效应（描述性）：Astra 与 Jev 的逐国效应相关 0.91（prompt）/ 0.93（tips）——两者面对同一份条件分配，对同一批 persona 的反应也相近；prompt 的单国效应里，仅条件分配一项的抽样标准差就有 0.06–0.09（置换空分布的中位数），而跨国标准差是 0.11–0.13。两者与真人逐国效应的相关，prompt 约 −0.15，tips 约 +0.08。每格 30 人时，国别这一层检验不了。

### 读法

1. **旗舰档看得见核看不见的那两个效应。** 同一批人、同一份判据，两种干预上都是 Astra 通过、Jev 失败；配对差值的区间都不含零（prompt +0.077，15 国中 13 国同向；tips +0.030，11 国同向）。注意力类、提示类干预的盲区不是"从文字描述预测行为"这件事本身的极限，而是核的局限。C3 里"风洞看不见这两类干预"的说法，要改成"**核看不见，旗舰档看得见方向**"。
2. **方向和通道都对，幅度偏小。** 两种干预下，Astra 都预测真、假新闻的转发一起下降、假的降得更多——正是真人的模式。prompt 的汇总效应是真人的 41%（假新闻的下降约为真人的一半：−0.097 对 −0.180），tips 是 60%。prompt 上它的区间 [0.010, 0.094] 与真人的 [0.089, 0.165] 只在边缘相接：它低估了效应。核在 prompt 上两条通道都朝错的方向走（预测提醒之后人们更愿意转发），在 tips 上方向对、但只有真人的五分之一。
3. **两次通过都不宽裕。** 单侧 p 分别为 0.012 与 0.026。判据是按干预分别判定、没有多重比较校正，判定照此成立；但若对两种干预做 Bonferroni 校正（各 0.025），tips 恰好不过。tips 的证据应读作"方向一致、强度边缘"。
4. **最重要的保留：它可能是在"认出范式"，而不是在推断。** 两种干预都是文献里有名的效应（accuracy prompt：Pennycook 等 2020、2021；数字素养提示：Guess 等 2020；本数据集 Arechar 等 2023 本身也是），都发表于 2020–2023 年，很可能在旗舰档的训练数据之内（其训练截止日期未经核实）。模型没被告知任何研究信息，但上下文（先请人评一条标题是否准确；一组识别假新闻的提示）对熟悉这些范式的读者一眼可辨。本次运行区分不了"从处境推断出效应"和"认出范式、套用已知结论"。对风洞来说真正要问的是"对还没人测过的干预能否预测"，这个数据集回答不了。
5. **与 SocSci210 的结果要一起读。** 在 SocSci210 的 304 个可靠对比上，旗舰档的符号准确率没有显著高于 Jev（+0.026 [−0.031, +0.083]），三个模型有共同盲区（A3b）。一边是跨几十个研究的平均，一边是两个著名的干预。合起来最稳妥的说法：**能力提升的收益落在个别（可能是文献里有的）效应上，没有普遍改善对条件效应方向的判断**。"收益是否集中在文献里有的效应上"是一个可检验的假设，尚未检验。

### 成本

每条预测 453 token（Codex 计数，含外壳开销）。按 $10 / $50 每百万 token 的价目，每千次预测 $4.5（全按输入计）到 $22.6（全按输出计）；核在 C3 的实际账本是每千次 $0.032（$3.905 / 122,253 条），即**约 140 到 710 倍**。墙钟时间合计约 106 分钟，也远长于核。

### 对项目的含义（在 C3 之上追加，C3 的结论保持原样）

- G-C 对核的判定不变：条目层面通过，干预层面失败。
- 风洞的授权范围分成两档。**核**：内容层面的初筛（哪些说法更可能被相信或转发），跨语言可用。**旗舰档 LLM**：此外还能给出 accuracy prompt、数字素养提示这类（文献里有的）干预的汇总方向，幅度约为真人的四到六成；不能用于逐国比较，也没有证据表明能推广到新型干预。

后续（2026-09-22）："认出范式还是推断"在 SocSci210 上按结果是否公开分组检验过（`A3c.md`）：未检出差异，区间很宽，既不支持也不排除记忆解释。
