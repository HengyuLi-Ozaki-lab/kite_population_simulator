# S1：规模演示——20,000 条实时预测的吞吐与单价，制表档 10⁴–10⁶ agent 的执行（v4 §3 C）

规划：v4 §3 C · 脚本：`scripts/c_scale_demo.py`（live / execute）· 输出：`results/c/20260923-113433-live/{predictions.jsonl, ledger.json, throughput.json}`、`results/c/execute.json` · 花费：**$0.32**（预算 ≈ $0.6）· 日期：2026-09-23

## 问的是什么

系统的"大规模"主张需要两个现场数字：(i) 核在速率上限附近的实测吞吐、延迟与单价（每条预测都是新的、没有缓存可依赖）；(ii) 预测/执行分离之后，从状态表执行 10⁴–10⁶ 个 agent 的速度与内存，以及公共随机数与 Rao-Blackwell 期望在这一层带来的方差收益。顺带演示已付费的 D1 锚点如何零成本地修正一份新人群。

## live：20,000 个全新状态

设置：Epstein 第 3 波，按任务哈希序排在第 231–730 位的 500 名完成者（与 D1 的 230 人不相交）× 20 张卡 × 2 个条件（对照、tips）= 20,000 个状态；核 = Jev p3（两个选项各一个 Noul）；并发 16，限流 960 请求/分（发布上限 1,200 的 80%）。

| 量 | 值 |
|---|---|
| 预测数 | 20,000（首轮 19,999：1 条 Cloudflare 520，续跑补齐） |
| 墙钟 | 920.7 秒 |
| 吞吐 | **1,303 条/分**（含缓存命中）；实时调用 14,159 次 = **922 次/分**（贴着 960 的限流） |
| 缓存命中 | 5,840 条（29.2%）：这些新人的"persona 文本 × 卡 × 条件"与早先某个状态完全相同（人口学画像相同即渲染相同），无需再问——制表档"唯一状态数 < agent 数"的现场例子 |
| 延迟 | p50 **213 ms**，p95 304 ms |
| 花费 | $0.322 → 每千条**新**预测 **$0.0227**（全部 20,000 条摊下来 $0.016/千条）；畸形分布 0 |

## execute：从表执行

表 = 上面的 20,000 个状态（500 persona × 20 卡 × 2 条件 → P(yes)）。人群 = N 个 agent，agent i 携带第 i mod 500 个 persona；每个 agent 在 20 步里各看一张卡，在两个条件下各决定一次，同一 (agent, 步) 共用一个事件键随机数（公共随机数）。

| 档 | agent 数 | agent-步 | 秒 | agent-步 / 秒 |
|---|---|---|---|---|
| 向量化（SplitMix64 事件键 + 逆 CDF） | 10⁴ | 2×10⁵ | 0.007 | 2.7×10⁷ |
| 向量化 | 10⁵ | 2×10⁶ | 0.075 | 2.7×10⁷ |
| **向量化** | **10⁶** | **2×10⁷** | **0.90** | **2.2×10⁷** |
| 标量（blake2b 事件键，逐 agent） | 10⁴ | 2×10⁵ | 0.95 | 2.1×10⁵ |

峰值常驻内存 685 MB（含标量表与 10⁶ agent 的数组）；一台笔记本。

**公共随机数**：10⁴ agent、100 个种子，tips − 对照的辨别力效应的标准差：共用随机数 **0.00072**，各条件独立抽 0.00303——方差降到 1/18，即同样精度少用 18 倍 agent。**Rao-Blackwell 期望**（直接对分布求和）没有抽样误差：对照 0.1385、tips 0.1606、效应 +0.0221；10⁶ agent 的 Monte Carlo 与之差在 10⁻⁴ 量级。

**已付费锚点的复用**：D1 记录的第 3 波 tips 六个单元的旗舰偏移 + 冻结的单元边界，直接倾斜这 500 名新 persona 的 tips 分布（6/6 单元可行，零次新旗舰调用）：修正后 tips 0.1450、效应 +0.0065。这只是"修正可以搬到新人群上"的演示——D1 里第 3 波 tips 恰是混合核低估最多的效应（真人 +0.027、核 +0.023、混合 +0.006），这里原样复现了那个数字，不是新的证据。

**差异区间**：按 D2 的核参数（β 0.925、τ 0.037、σ 0.080），真人效应的 90% 区间为核 [−0.125, +0.165]、修正后 [−0.139, +0.151]；区间半宽 0.145 远大于效应本身——与 D1 附录一致：这一层的不确定性由差异模型决定，与 agent 数无关。

## 读法

1. 规模叙事的三个数字都有了现场实测：**每千条新预测 $0.023、p50 延迟 0.21 秒、贴着限流 922 次/分**；执行层 **10⁶ agent × 20 步 0.9 秒**。核的成本在预测、不在执行——预测一次、执行无限次的分离是成立的。
2. 29% 的"新"状态其实是老状态：人口学 persona 的渲染有大量重复，真正的唯一状态数远小于 agent × 情境数。这是制表档的收益来源，也是 A 阶段"persona 几乎不携带个体信息"的另一面。
3. 公共随机数与 Rao-Blackwell 期望把执行层的 Monte Carlo 噪声压到可忽略；剩下的全是差异模型的宽度。论文 §7 的规模图应与 §6 的"模拟人数只压 MC 区间"图并排放。
