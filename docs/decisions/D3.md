# D3：配对稀疏旗舰锚点在 SocSci210 上的检验——开发集定 k 与斜率，测试集一次

规划：v4 §3 B · 判据：`configs/eval/socsci210_paired_anchors.yaml`（冻结于 c701187，测试集锚点运行之前）· 脚本：`scripts/b_paired_anchors.py`（count / astra / analyse）· 输出：`results/b/{20260923-011209-dev-paired-gpt-6-astra, dev-20260923-022128.json, 20260923-022351-test-paired-gpt-6-astra, report.json}` · 日期：2026-09-23

## 问的是什么

多保真度核的通用版本：核预测人群的每个状态；旗舰只在每个任务的 3 个锚点 persona 上被调用，且同一 persona 在该任务的**每个条件**下都被预测（配对，同 D1）；混合核的条件效应 = 旗舰在锚点上的配对效应，参考条件保留核的水平。问三件事：(i) 这样得到的人群是否复现旗舰的条件效应（近似保真度）；(ii) 是否因此得到旗舰对真人的决策质量（人类保真度）；(iii) 配对是否比同预算的未配对锚点更好。

与 D1 的差别：SocSci210 是 Jev 的原生基准（TESS 调查实验，被试间设计，每格 5 个旗舰受访者的运行已有），研究数多（开发 91、测试 37），效应类型杂；没有"真伪 × 基线三分位"这种领域单元，单元就是研究 × 条件 × 题。

## 设计

- 锚点：每个可比 (研究, 题) 块里按哈希序取前 3 个真实受访者（嵌套，k = 1, 2 是子集），每人在块内每个条件下各预测一次；条件的刺激取该格哈希序第一位受访者看到的那份（24% 的格内有多份刺激变体，这是一个已知的近似）；一批里不出现同一任务的两个条目。
- 混合核（单元均值层）：hybrid(c) = kernel(c₀) + shift(c)，shift(c) = 锚点在 c 与 c₀ 下位置差的均值；c₀ 为块内第一个条件。斜率（真人效应对模型效应的 OLS，开发集）只用于"校准 MAE"这一行：核 0.984、旗舰 0.591、混合 0.556。
- 系统：kernel（测试集为 136,901 条全人群运行）、flagship5（每格 5 人未配对）、flagship3（flagship5 的前 3 人，未配对、与 k = 3 同预算）、hybrid_k1/2/3。
- 运行：开发集 7,293 条锚点、495 批、4.08M token、63 分钟，0 缺失；测试集 2,082 条、129 批。

开发集读法：
1. 3 个配对锚点让人群拿到旗舰的决策质量：符号准确率与 flagship5 无法区分（−0.006），捕获收益略低（−0.033，含 0），对核有显著的符号准确率增益（+0.038）。
2. 任务内 r（幅度对齐）没有增益：混合与核持平、低于 flagship5（−0.047）。原因是 3 个锚点的效应估计带噪声，而 r 对幅度噪声敏感，符号与收益只看方向。
3. **在 SocSci210 上，配对不带来 D1 里那种优势。** D1 里配对锚点以 1/8 的调用量胜过未配对审计，很可能因为审计池是另一批 persona（30 人）带自己的抽样噪声，而锚点与人群同池；这里 flagship5 的受访者本来就是各格的真实受访者，未配对就已在池内。加上 persona 几乎不携带个体信息（r = 0.013），配对能消掉的噪声本来就少；刺激变体的近似还略伤配对锚点。
4. 核与旗舰在这个基准上本来就高度一致（效应相关 0.86，与旗舰自身分半一致性 0.87 相当），所以"近似保真度增益"在开发集上不显著（+0.054）。测试集上核与旗舰的一致性只有 0.61，增益的空间更大，但区间也更宽（判据里的功效注记）。

## 读法

1. **主终点通过，但险。** 测试集上核与旗舰效应的相关只有 0.61（开发集 0.86），旗舰自身分半一致性约 0.6；3 个配对锚点把人群与旗舰的一致性推到 0.71，增益 +0.10，下界 +0.003。这说明锚点把人群推向了旗舰，也说明"复现旗舰"的上限就是旗舰自身估计的可靠度。
2. **人类保真度上最强的是捕获收益**（G-A 定义的决策价值：按模拟选最高/最低条件时拿到的真人效应份额）：核 0.268 → 混合 0.386，**+0.119 [+0.014, +0.224]**，相对提高 44%；k = 1、2、3 都是 +0.11–0.12 且区间都排除 0；而旗舰自己的 5 人/格运行只有 +0.069（含 0）。这是事先列出、方向已预期的**次要终点**，写作时如实标注。
3. **一个 persona 就够**：k = 1（每任务 1 个 persona 在各条件下各一次，694 次调用，人群状态的 0.5%）已拿到 +0.114 的收益、+0.046 的符号准确率；k = 2 的符号准确率 0.742 比旗舰的 5 人/格运行高 0.071 [+0.022, +0.128]（90%）。
4. 任务内 r 不变（+0.026），原始 MAE 更差：混合与旗舰一样反应过度（幅度比 1.75 vs 核 0.68），而测试集的真人效应小；开发集斜率校准后三者相当（0.052 / 0.055 / 0.056）。**方向与决策价值来自旗舰，幅度要靠差异模型按部署数据重估**（D2 的老结论）。
5. 分歧诊断在测试集上复现了一半：一致处（79%）准确率 0.74；分歧处混合 0.59 对核 0.41——而未配对的 flagship5 在分歧处与核各对一半。配对锚点在**方向**上比未配对的 5 人运行更有信息，与"配对对近似 flagship5 没帮助"不矛盾——flagship5 自己就是带噪声的裁判。
6. 同预算配对 vs 未配对：收益 +0.047、符号 +0.012、r −0.038，都含 0，方向与开发集相反。不宣称配对更好；能说的是"每任务 1–3 次旗舰调用，就拿到旗舰级（或更好）的决策质量"。

## 对论文的一句

在 37 个留出的 SocSci210 实验上（判据在锚点运行前冻结），每个任务 1–3 次配对的旗舰调用（人群状态的 0.5–1.5%）把核模拟人群的捕获决策收益从 0.27 提到 0.39（+0.12，95% 区间 +0.01 到 +0.22），高于旗舰自己每格 5 人的运行（0.34），并把人群的条件效应推向旗舰（相关 0.61 → 0.71，主终点通过）。
