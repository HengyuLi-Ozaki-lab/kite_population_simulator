# A3：同一批条目上的 LLM 对照 —— GPT-5.6 Luna（最便宜档）与 Jev 大体相当，错在同一批对比上

日期：2026-09-21 · 对照：本机 Codex CLI 的 `gpt-5.6-luna`（reasoning effort low），配置提交于 dc3acb7 之后运行测试集一次
条目：测试集每格前 5 名受访者的嵌套子样本，3,615 条（Jev 侧 3,613 条，缺的 2 条属于额度耗尽时失败的 32 条）
复现：`uv run python scripts/a3_codex_baseline.py --split test`；Jev 侧 `scripts/nested_subsample.py --max-per-cell 5`；两侧再跑 `scripts/a1_decision_value.py`

## 先更正一个标签

**Luna 是 GPT-5.6 系列里最便宜的一档，不是旗舰。** 官方价目（2026-09-21 取自 `developers.openai.com/api/docs/pricing`，经抓取工具的摘要模型读出，每百万 token，输入 / 输出）：gpt-5.6-luna $0.20 / $1.20；gpt-5.6-terra $2 / $12；gpt-5.6-sol $4 / $20；gpt-6-astra $10 / $50。此前我在沟通中把它称作"旗舰 LLM"是错的。本文的结论因此是"与便宜档 LLM 的对照"；**旗舰档的精度没有测过**。

## 设置的公平性

LLM 拿到的与 Jev 相同：渲染后的 persona、带刺激材料的题目、选项描述，同样的第三人称预测式问法，要求给出每个选项的概率。提示语多了一句 Jev 看不到的话（提醒真实作答是有分散的），因为不加这句的口述概率已知会过度自信，一个被设计成会输的基线什么也证明不了。多条目共用一次调用，但同一批里不放同一任务的两个条目——并排看到同一问题的两个条件等于让模型直接对比，这是单条目调用的 Jev 没有的优势。

## 读法

1. **边际层（L1）打平。** Luna 的分布距离略好，Jev 的准确率与校准略好，差距都很小。这与 G1 里靠归一化得到的"与零样本 GPT-4o 打平"一致，而且这次不需要任何归一化论证。
2. **处境层（L2）Luna 的相关更高，但反应过度。** Luna 跨条件的变动与真人更一致（r 差值的区间不含 0），但变动幅度是真人的 1.61 倍；Jev 的幅度接近真人（0.89）而对齐程度较低。折算成决策价值，Luna 的符号准确率略高（区间下端恰在 0），捕获收益无法区分。
3. **两个模型错在同一批对比上。** 304 个可靠对比中：都对 57.9%，只有 Jev 对 6.6%，只有 Luna 对 11.8%，**都错 23.7%**；若两者的错误相互独立，都错应为 10.8%。一个校准决策模型与一个推理 LLM 在同一批实验效应上失手，说明决策价值的上限主要来自**这些效应本身难以从文字描述推出**，而不是某一个模型的缺陷。两者离真人半样本先导都很远。
4. **成本。** Jev 每千次预测 $0.0344（实测）。Luna 这次经 Codex CLI 报告共 1,955,016 token（含 CLI 自身的系统提示开销，输入 / 输出的拆分未知），按价目只能给区间：

| 模型 | 按全输入计 … 按全输出计，每千次预测 | 相对 Jev |
|---|---|---|
| gpt-5.6-luna | $0.108 … $0.649 | 3 … 19 倍 |
| gpt-5.6-terra | $1.08 … $6.49 | 31 … 189 倍 |
| gpt-5.6-sol | $2.16 … $10.82 | 63 … 314 倍 |
| gpt-6-astra | $5.41 … $27.04 | 157 … 786 倍 |

   后三行是"同样的 token 数乘以该档价格"的外推，不是实测。**对便宜档 LLM，Jev 的成本优势大约是一个数量级，不是两个**；对旗舰档价格是两到三个数量级。G1 的第三条判据（单位成本 ≤ 旗舰 LLM 的 1/50）按旗舰档价目成立，但要带上两个限定：token 拆分未知；旗舰档的精度未测。
5. **对论文叙述的含义。** "Jev 以低两个数量级的成本达到 LLM 的精度"这句话不能照原样写。准确的说法是：在这类任务上，一个校准决策模型、一个便宜档 LLM 达到的水平相近，都显著好于无信息、都远不及真人先导；Jev 比便宜档 LLM 再便宜约一个数量级、单次延迟约 0.24 秒。旗舰档是否更好，是一个需要花钱才能回答的开放问题。

## 限定

- Codex CLI 是一个带系统提示的 agent 外壳，不是裸 API；其 token 计数与延迟（每次调用约 18 秒、约 15 条）不能当作 API 的数字。
- 价目经摘要模型读出，未逐字核对页面原文。
- 对"都错"的那批对比是什么类型的效应，尚未分析；这属于对测试集的新探索，应先在开发集上定好分析方法。

## A3b：旗舰档对照（GPT-6 Astra，高推理强度，2026-09-22）

设计与判据先于旗舰档的任何测试预测提交（`configs/eval/flagship_baseline.yaml`，ffcb4a7）。条目与 Jev、Luna 完全相同（3,615 条），提示词与分批规则不变。运行目录 `results/20260922-130953-socsci210-test-codex-gpt-6-astra-high`；比较脚本 `scripts/a3b_three_models.py`。215 次调用、2,570,752 token、28 分钟，无缺失。

### 读法

1. **边际层随模型能力明显提高。** Astra 的分布距离比 Jev 低四分之一。按各自均匀基线归一化是 0.1185 / 0.1771 = **0.67**——优于论文里在 170 个研究上微调过的 Socrates 模型（0.744），接近经验下界（0.616）。（任务集不同，这里依赖 G1 的归一化论证。）
2. **决策层没有跟着提高。** 与 Jev 相比，符号准确率与捕获收益的差都不显著；同一裁判下 Astra 为 0.704，对真人先导 0.985，补上的差距同样是约四成。大效应档（> 8 个百分点）上 Astra 0.639、Jev 0.634、Luna 0.662、真人先导 0.919。两个 LLM 的任务内相关都高于 Jev，但都反应过度（幅度比约 1.6），换不成更好的决定。
3. **共同盲区延伸到了旗舰档。** 三个能力、价格、架构都差得很远的模型，在同一批实验效应上失手，频率是独立时的 3–11 倍。决策价值的上限主要来自"这些效应从文字描述里推不出来"，而不是某个模型不够强。这是本项目对领域最通用的一条发现，现在有了旗舰档的支持。
4. **对论文的含义。** "模型越强，排行榜指标越好；对模拟真正重要的条件效应方向却没有变好"——这与 F3（聚合指标可以被条件盲预测器刷分）互相印证：领域里通行的评估方式，恰好奖励了会进步的那一面，看不见不会进步的那一面。

### 成本（按 2026-09-21 取得的价目）

Codex 报告 2,570,752 token（含外壳自身的提示开销，输入输出拆分未知），合每条 711 token。按 gpt-6-astra 价目 $10 / $50 每百万 token，每千次预测 $7.1（全按输入计）到 $35.6（全按输出计），是 Jev（$0.034）的 **约 210 到 1,050 倍**。

**成本叙述的最终形态**：在边际层，花两到三个数量级的钱确实买到更好的分布（0.136 → 0.101）；在决策层，买不到。

### 补充：误信息领域的旗舰档对照（2026-09-22）

同一旗舰档在 Arechar 的 15 国留出部分上，按冻结判据**通过**了 accuracy prompt 与数字素养提示两项干预检验，而同一批受访者上的 Jev 两项都失败（配对差值 +0.077 [0.055, 0.099] 与 +0.030 [0.008, 0.051]；详见 `C2.md` §C3b）。这与上面"决策层买不到"并不矛盾，但限定了它的范围：SocSci210 是跨几十个研究、几百个对比的平均，Arechar 是两个在文献里很有名的干预。成本叙述相应补一句：**平均而言，决策层买不到；在个别著名的干预上，花两到三个数量级的钱能买到方向（约为真人效应的四到六成）——而这可能来自对文献的记忆，不是推断。**
