# B1：自我条件化会让边际漂移 —— 检测到，机制已定位，保序校正可修复（单研究）

日期：2026-09-21 · 模型 `jev-1.13.0`（p3）· 全部命中缓存，花费 $0
数据：**开发集** sffyb（干净）、nj5dx（同一人同一题号下有多条刺激，单独报告）
复现：`PYTHONPATH=scripts uv run python scripts/b1_marginal_drift.py --studies nj5dx sffyb --windows 0 1 3`，
诊断：`PYTHONPATH=scripts uv run python scripts/b1b_drift_diagnostics.py`

## 判据（先于首次运行提交，见 05b4c3b）

独立作答（窗口 0）的答案从同一批预测分布里换种子重抽，到真人单元分布的距离本身就会变动，这个变动范围是噪声地板。**"未检测到漂移"= 窗口 3 的距离不超过窗口 0 在 200 次重抽中的 95 分位。** 只在干净研究 sffyb 上判定。

## 结果：检测到漂移

| sffyb，24 个单元 | 抽样分布到真人的距离 | 相对地板（均值 0.2400，p95 0.2507） | 交还给均匀猜测的优势 |
|---|---|---|---|
| 窗口 0 | 0.2391 | 地板内（56% 的重抽不比它近） | — |
| 窗口 1 | 0.2808 | **超出**（200 次重抽无一达到） | 61.5% |
| 窗口 3 | 0.2585 | **超出**（同上） | 28.0% |

均匀猜测在这些单元上是 0.3074。"交还的优势"用无采样噪声的平均预测分布计算。

不是往极端漂：落在量表两端的答案占比几乎不变（0.370 → 0.379；真人是 0.551）。窗口 1 最糟、窗口 3 好一些，且靠后的题受影响更大（窗口 3 相对窗口 0：前半 +0.013，后半 +0.026）。

nj5dx 上核相对均匀几乎没有优势（0.0875 对 0.0995），三个窗口的距离无实质差别；其窗口 0 的种子 0 抽样恰好落在地板的第 99 百分位，换 5 个种子后均回到地板内，属于偶然。

## 诊断（探索性，零成本）

1. **地板可靠**：窗口 0 的请求不依赖抽样结果，换种子 1–5 重跑模拟，sffyb 的距离为 0.2361–0.2445，全部在地板内。
2. **问题不在条件化本身，而在喂回模型自己的误差**：E3b 用**真实**答案作历史时，平均预测分布到真人的距离在 sffyb 上是 0.2401（0 条）→ 0.2057（3 条）→ 0.1728（6 条），**明显变好**。模拟里变差，是因为模型自己抽的答案本来就偏离真实分布（0.24），以此为条件会把偏差叠加。窗口越短，单个答案的锚定越强。
3. **依赖结构与边际可以分开**：对每个单元做随机化的分位数映射，把自我条件化的抽样映射到独立作答的平均预测分布上——题内每个人的排位不变，边际按构造恢复。

| sffyb | 到真人的距离 | 一致性量级 | 结构 | 相邻 / 远距（真人 1.81） | 远距题 / 真实 |
|---|---|---|---|---|---|
| 窗口 0 | 0.239 | 0.454 | 0.159 | 1.05 | 0.511 |
| 窗口 3，原始记忆 | 0.259 | 0.752 | 0.658 | 2.12 | 0.719 |
| 窗口 3 + 保序校正 | **0.240** | **0.729** | **0.646** | 2.01 | 0.708 |

边际回到地板之内，恢复出的一致性保住约 97%。离散量表上的同值必须随机打破，所以一致性只会略降，不会升。

## 判定与含义

- **按事先判据：不通过。** 直接把自己抽到的答案写进 state，会让人群的边际分布变差；v2 规划 G-B 的第一个条件对"原始自我记忆"不成立。
- **候选架构**：记忆提供依赖结构，无记忆的制表核提供边际，两者用保序校正接起来。后者正好是缓存友好的那一半，几乎不增加成本。在人群同时面对同一内容的模拟里，校正是对每条内容的人群级操作；暴露不同步时要改成按选项的加权（以独立作答的人群边际为目标），细节留给 D 的设计。
- **这是在发现问题的同一个研究上找到的修法**，证据强度是「开发集单研究、探索性」。B2 的多研究重复必须把三个臂（窗口 0、窗口 3、窗口 3 + 校正）一起跑，并**同时**对一致性与边际两个轴预先写定判据。
- **顺带的发现**：给定 6 条真实作答，其余题目的**人群层面**分布预测改善 28%（0.240 → 0.173）。这指向一个此前没有列入的应用——问卷缩短 / 部分作答的补全——目前只有一个研究的证据，列为待验证。
