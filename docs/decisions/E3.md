# E3：个体一致性 —— Jev 建模的是处境，不是人

日期：2026-09-21 · 模型 `jev-1.13.0` · 冻结问法 p3
数据：**开发集** 5 个研究（mp3dr、nj5dx、sffyb、9263n、r5hwx）、42 道题、19 个条件、每条件约 150 人、22,623 次预测、$0.76
复现：`uv run python scripts/e3_item_correlation.py --studies mp3dr nj5dx sffyb 9263n r5hwx --max-participants 150 --max-usd 2`

## 问题

Jev 的问题是并行且互相隔离求值的。给定 persona，同一个人各题的答案是条件独立的。真人的答案之间还有人口学解释不了的一致性。**persona 能恢复多少？**

## 结果

同一批人、同一批题，三个 Spearman 题间相关矩阵（按题对数加权）：

| | 平均绝对相关 |
|---|---|
| 真实作答 | **0.326** |
| Jev 预测分布的**均值**（persona 驱动，无采样噪声） | **0.795** |
| 从分布中**采样**一个答案（模拟实际产生的） | **0.040** |

结构恢复（真实两两相关 vs 模拟两两相关的相关）：均值 r = **0.597**，采样 r = 0.152（后者在各条件间从 −0.76 到 +0.71 剧烈波动，基本是噪声）。

## 真实相关的分解（纯计算，无 API）

把真人作答按一个粗人口学分组（党派 × 意识形态 × 年龄段 × 教育，每组 ≥5 人）拆成组间与组内：

| | 平均绝对相关 |
|---|---|
| 总计（个体层面） | 0.313 |
| 组均值之间 | 0.429 |
| **组内残差** | **0.282** |

**注意不要把 0.429 除以 0.313 说成"人口学能解释 137%"。** 组均值经过平均，噪声被削弱，其相关天然高于个体相关（生态相关）。两者不是同一尺度，不能相除。

正确的对照分两层：

| 层面 | 真实 | Jev | 判读 |
|---|---|---|---|
| 平滑后（组均值 ↔ 预测均值） | 0.429 | 0.795 | Jev 是人口学天花板的 **1.9 倍** |
| 个体（实际作答 ↔ 采样） | 0.313 | 0.040 | Jev 交付了 **1/8** |

## 诊断

1. **过度刻板化**：Jev 的 persona 效应比人口学本身所能支持的上限还高 1.9 倍。它从人口学标签读出了数据不支持的一致性。
2. **persona 通道太窄**：由 0.040 ≈ 0.795 × 比例 反推，预测方差里只有约 **5%** 是人与人之间的差异，95% 是同一个人分布内部的宽度。采样一次就把相关冲没。
3. **大部分真实一致性不是人口学的**：组内残差 0.282 是真实一致性的主体，按定义对任何人口学 persona 不可见。

与既有发现拼合：Jev 的**跨条件**变动幅度是真人的 0.76 倍（G1b），**跨人**的有效方差只有约 5%。**它对处境反应良好，对个体几乎不反应。**

## 对项目的影响

| 主张 | 影响 |
|---|---|
| C1（核的保真度） | 不变，已通过 |
| **C2（个体自洽）** | **按原设计不成立。** 需重述为：个体一致性必须由一个显式、经标定的潜变量层提供；核本身给不了，本实验量化了差多少、为什么 |
| C3（重复运行买到统计功效） | 基本不受影响——干预是**处境**操纵，而 Jev 正好对处境敏感 |
| C4(a)（干预风洞） | 不受影响，同上 |
| **C4(b)（混合真人/硅基抽样）** | **应当撤回或大幅限定。** 它的价值建立在个体层面的预测力上，而这里只有 1/8 |

## 下一步的设计约束（由本结果推出，非事先假设）

分层潜变量不是优化而是必需，且必须同时满足两条：

- **增大人与人之间的方差**，直到采样后的题间相关落在真实的 ~0.31 附近——这是一个**标定**步骤，不能放任自由；
- **同时抑制过度相关**：persona 通道已经是天花板的 1.9 倍，单纯放大它会让刻板化更严重。目标是「方差变大、跨题相关变小」，比原先设想的要难。

由此可得的一个可检验预测：潜变量的方差调到合适值时，采样相关能匹配 0.31，但**结构保真度上限约为 r = 0.6**（即 Jev 均值的结构与真实结构的相关）。

## 更正（2026-09-21，同日，交叉验证之后）

上文「诊断」一节的前两条**判断错误**，据以下两项补充分析更正。原文保留以便对照。

### 1. 人口学的真实天花板是 ~0，不是 0.429

0.429 是**样本内**的组均值相关（生态相关）。改用**交叉验证**的组均值预测个体作答：

| | 平均 | 中位数 |
|---|---|---|
| 交叉验证的人口学组均值 | **0.013** | −0.005 |
| Jev 的逐人预测均值 | **0.169** | 0.141 |

**人口学对个体作答几乎没有样本外预测力**，而 Jev 在 136 个单元里有 **109 个超过它**。原因是组均值估计器只能在样本内学（40 多个组摊在 150 人上），而 Jev 带着世界知识，不必从这批人里现学。

因此「Jev 过度刻板化 1.9 倍」的说法**不成立**——那是拿它和一个样本内虚高的量比较。

### 2. 跨人散布是恰当的，不是"窄了 6 倍"

一个与真值相关为 r 的校准预测器，其标准差应为 `r × sd(真值)`：

| | 值 |
|---|---|
| 预测的跨人标准差，实测 | 0.0383 |
| 其准确率所支撑的标准差 | 0.0522 |
| 比值 | **0.73**（逐单元中位数 0.86） |

略微过度收缩，但量级正确。原文拿它与**真人散布**（0.253）相比得出"6 倍"，比较对象选错了——那等于要求一个只能解释 17% 信号的预测器散布得和真值一样大。

### 3. 修正后的诊断

- **个体可预测性本身就极低。** 这些研究里，个体作答的绝大部分变异对**任何**基于人口学的方法都不可见。
- **Jev 在输入允许的范围内表现良好**，明显优于样本内统计估计器。
- **采样后题间相关只有 0.040，主要是正确行为而非缺陷**：只能预测 17% 的个体信号，模拟出的人自然接近可交换。
- **真正残留的缺陷是信号的"形状"**：逐人预测均值跨题相关高达 0.795，近乎单一般因子驱动一切；真实的个体一致性更具题目特异性。

### 4. 对结论的影响

C2「按原设计不成立」的判断**不变**，但理由变了：不是"Jev 不会读人"，而是**人口学 persona 本身承载不了个体一致性，换谁来都一样**。

这把瓶颈从模型转移到了**输入**上，也因此指出了可行的方向：要模拟连贯的个体，必须注入**人口学之外的真实个体信息**（如作答历史），或显式采样并标定潜变量。

## 方法学限定

- 只用了开发集研究，测试集未触碰（脚本对测试集研究直接拒绝运行）。
- 人口学分组是粗粒度的四属性组合；更细的分组会抬高组间相关但每组人数骤减。0.429 应读作一个估计，不是精确天花板。
- `r5hwx` 每条件只有 6 个题对，`structure_sampled` 在这些条件上不可信。
