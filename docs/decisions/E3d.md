# E3d：LLM 压缩作答历史 —— 准确率持平，价值在可扩展性

日期：2026-09-21 · Jev `jev-1.13.0`（p3）· 压缩模型：本机 Codex CLI 的 `gpt-5.6-luna`（reasoning effort low）
数据：**开发集** nj5dx、sffyb，591 人，每臂 2,921 次预测
复现：`uv run python scripts/e3d_compressed_history.py --studies nj5dx sffyb --max-usd 2`（摘要缓存于 `results/e3d/summaries.json`，提示词与模型记录于 `results/e3d/codex.json`）

## 设计

每人固定以其**前 6 题**作为历史、其余题作为预测目标，所以"原始"与"摘要"两臂携带**完全相同的内容**，只差表示形式。摘要提示词明令禁止推断答案之外的任何东西——一个会编造人格的 LLM 会让模拟**看起来**更连贯，却对真实个人毫无增益。

两人试跑时人工核对了摘要：未提及人口学、未归纳标签，且正确读出了一道反向计分题（1 = 强烈同意，7 = 强烈不同意）。

仍是**作弊上界**：历史里是真实作答。

## 结果

| 臂 | r（均值） | r（中位数） | 散布 / 应有散布 | 相对回归天花板 | Jev 花费 |
|---|---|---|---|---|---|
| 无历史 | 0.269 | 0.197 | 0.834 | 81% | $0（缓存命中） |
| 原始 6 条 | **0.380** | 0.440 | 0.871 | 114% | $0.179 |
| LLM 摘要 | **0.376** | **0.480** | **0.908** | 113% | **$0.111** |

回归天花板（同样 6 条答案，交叉验证岭回归）：r = 0.333。591 条摘要全部写成。

## 判定

**按事先写定的判据（以均值为准）：摘要 ≈ 原始——压缩既不损失也不增益准确率。** 中位数（0.480 对 0.440）与校准（0.908 对 0.871）都偏向摘要，但判定不因看到结果而改换统计量。

## 为什么没有增益：B 的前提在它自己的设计下不成立

E3d 的动机来自 E3b："6 条原始历史只达到回归天花板的 83%，信息在、Jev 吃不下"。而在本实验的固定历史设计下，Jev 用 6 条原始历史就达到了天花板的 **114%**——**不存在可供压缩弥补的缺口**。E3b 的那个缺口依赖于随机抽取历史的设计，见 E3b 文末更正。

## 真正的价值：可扩展性

同等准确率下，摘要让 state **缩短 38%**（输入 token 2.64M 对 4.25M）、成本**降低 38%**。在 6 条时原始历史尚能放下；模拟推进到数十、上百条时，原始历史会无界增长、触及上下文上限，**摘要则保持有界**。因此 LLM 压缩在模拟架构中的角色是**长历史的有界记忆**，不是小规模下的准确率提升。

分工也验证了是干净的：LLM 概括真实信息，Jev 做校准决策，二者各做擅长的事。
