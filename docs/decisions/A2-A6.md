# A2 重校准 与 A6 有效样本量 —— 两项零成本的收尾测量

日期：2026-09-21 · 模型 `jev-1.13.0` · 全部基于已有预测，花费 $0
开发集运行：`results/20260921-221629-socsci210-dev-jev-p3-choice`（每格 50 人）；测试集运行：`results/20260921-012513-socsci210-test-jev-p3-choice`（每格 200 人）

## A2：p3 不需要温度重校准；Choice / Score 需要约 9 倍

在开发集上按个体真实作答的对数似然拟合温度 T（对 log p 除以 T 再归一化）：

| 问法 | 拟合温度 |
|---|---|
| **p3（逐选项 Noul，归一化）** | **1.05** |
| p1 / Choice | 9.06 |
| p2 / Choice | 8.21 |
| p1 / Score | 11.21 |

把 T = 1.05 应用到测试集，什么都没变：分布距离 0.1329 → 0.1334，ECE 0.0382 → 0.0372，条件敏感度 r 0.385 → 0.384。

读法：相对选择式的问法给出的分布，在个体层面错得足够自信，以至于最优的修正是把它几乎压平；逐选项的绝对判断不需要任何修正。v1 计划里"重校准后 ≤ 0.185"那一档判据因此用不上——冻结的问法本身就是校准的。这是"问法决定校准"最简洁的量化。

**关于斜率的更正。** 此前我把条件敏感度的斜率（测试集 0.50）说成"真实效应是 X，模拟出来大约是 0.5X"，方向反了。该斜率是真人变动对模拟变动的回归系数：**模拟出大小为 Y 的效应时，对真实效应的最佳线性预测是 0.5Y**。模拟变动的幅度本身是真人的 0.76 倍，并不小；只是其中与真人变动对齐的部分有限（r = 0.385）。开发集上该系数是 0.70，所以用开发集拟合的缩放去预测测试集的效应量，会高估约四成——效应**量级**不在可主张的范围内，这一结论不变。

## A6：一次模拟的单元分布约值 5 个真人；作为先验，扣除平滑本身的好处后约值 1 个

复现：`uv run python scripts/a6_kappa.py --dev <开发集运行> --test <测试集运行>`（规格先于运行提交）。距离为量表等距位置上的 Wasserstein，对单元直接取平均（与 G1 的"先研究内、再跨研究"平均不同，所以测试集上模拟的平均距离这里是 0.140 而非 0.1329）。

**等价样本量**——随机抽 n 名真人，其经验分布到全样本单元分布的平均距离，与模拟的距离相等时的 n：

| | 单元数 | 合并口径 | 逐单元中位数（四分位） | 不如 1 名真人的单元 | 至少值 20 名的单元 |
|---|---|---|---|---|---|
| 开发集 | 467 | 4.8 | 6.9（2.1–17.3） | 12.6% | 21.8% |
| 测试集 | 723 | **4.6** | 6.3（1.8–21.6） | 17.4% | 26.0% |

**作为先验的价值**——把模拟分布当作强度 κ 的 Dirichlet 先验，与 n 名真人合并。任何平滑对小样本都有帮助，所以同时跑一个均匀先验作对照；κ 在开发集上按 n 选定，原样用于测试集：

| 真人数 n | 只用真人 | + 均匀先验（κ = 2） | + 模拟先验（κ = 5 / 5 / 3 / 3） | 不用先验需要多少真人才能追平：均匀 / 模拟 |
|---|---|---|---|---|
| 5 | 0.1323 | 0.1055 | 0.0986 | 7.9 / 9.1 |
| 10 | 0.0932 | 0.0824 | 0.0796 | 12.9 / 13.9 |
| 20 | 0.0657 | 0.0618 | 0.0605 | 22.9 / 23.9 |
| 50 | 0.0415 | 0.0405 | 0.0402 | 52.9 / 53.9 |

读法：模拟先验相当于多出约 4 名受访者，但其中约 3 名是任何平滑都能给的；**扣除之后，模拟本身的增量约为 1 名受访者，且不随 n 变化**。

## 对 v1 主张 C4(b) 的结论

混合真人 / 硅基抽样在单元层面的价值可以忽略：对几百上千人的调查毫无影响，对极小单元也只相当于多问一个人。这与此前的粗估（个位数）一致，现在有了带对照的实测。论文里作为负面结果用一张表交代即可。
